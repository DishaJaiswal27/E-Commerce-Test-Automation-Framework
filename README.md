# 🛒 E-Commerce Test Automation Framework

A BDD-based UI test automation framework built using Selenium WebDriver, Java, Cucumber, TestNG and Maven.

The framework automates critical e-commerce workflows including authentication, product search, shopping cart operations, checkout and order placement.

---

## 🚀 Project Overview

This project is designed to demonstrate a scalable and maintainable Selenium automation framework following industry-standard practices such as:

- Page Object Model
- BDD with Cucumber
- Reusable components
- Explicit waits
- Centralized configuration
- Cross-browser execution
- Data-driven testing
- Logging
- Extent Reports
- Failure screenshots
- Maven execution
- Git/GitHub version control
